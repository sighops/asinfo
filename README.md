# asinfo

asinfo is a library providing local IP address to ASN lookups, and related AS information, using RIB snapshot data.  
It also provides facilities for downloading necessary data.

## Features

- Local IP address to ASN lookup
- Best matching IP prefix lookup
- IPv4 and IPv6 address support
- AS name lookup by ASN
- String search for ASN lookup by AS name
- List of all prefixes announced by an ASN
- List of collapsed prefixes announced by an ASN
- Address space size announced by an ASN
- Support for asplain, asdot, asdot+ formats
- CLI for local only use cases
- RIB snapshot downloads over HTTPS or FTP
